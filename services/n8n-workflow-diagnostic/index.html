Good to know

Why should I trust a diagnosis from you?

Six of our own workflows are published in the official n8n template library — each passed n8n's human editorial review and was live-tested with real executions before submission. The same checklist we use on our own work is the one we run on yours. AI helps us build and test; a human is accountable for every line of the report, and everything is in writing.

Is it safe to send my workflow export?

An n8n export contains the workflow's structure and settings, not your passwords or API keys — credentials stay in your instance. We read the export, we do not run it against your accounts, and we delete it on request once the report is delivered.

What can you not see from an export?

Anything that only shows up at run time: the actual data your services return, rate-limit responses, timing. When a finding needs a live run to confirm, the report says so and tells you how to confirm it yourself — or we do it as part of a repair.
